Welcome to my academic repository! This monorepo is dedicated to storing, documenting, and tracking my evolution throughout the **Software Engineering** degree at **FIAP** (São Paulo, Brazil).

Here you will find class notes, lab exercises, checkpoints, and practical projects developed during the course.

---

### 📂 Repository Structure (Subjects)

Here are the primary disciplines covered during this semester:

* 🐍 **[Computational Thinking Using Python](./computational-thinking-python):** Programming logic, algorithms, data structures, and hands-on Python applications.
* 🔌 **[Edge Computing](./edge-computing):** Hardware integration, IoT, sensors, and edge intelligence systems.
* 🎨 **[Front-End Design](./front-end-design):** UI/UX concepts, prototyping, wireframes, and visual design principles.
* 🌐 **[Web Development](./web-development):** Semantic HTML5, CSS3, JavaScript, and building responsive web pages.
